LIBRARY MANAGEMENT TASK
=======================

Build a library management system that allows librarians to manage books,
members, and borrowing activity.

Requirements
------------
- Add, update, view, and remove book records.
- Register and manage library members.
- Search books by title, author, category, or ISBN.
- Issue available books to members and record due dates.
- Return books and update their availability.
- Prevent issuing books that are already borrowed.
- Display overdue books and borrowing history.
- Validate required input and show clear error messages.

Expected Deliverables
---------------------
- A working library management application.
- Persistent storage for books, members, and transactions.
- A simple, user-friendly interface.
- Documentation describing setup, usage, and supported features.
